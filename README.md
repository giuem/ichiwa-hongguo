# ichiwa-hongguo

[一集（Ichiwa）](https://github.com/giuem/ichiwa)的红果短剧片源插件，基于 [openhongguo](https://github.com/beilunyang/openhongguo)（v0.4.1）改写为纯 JavaScript ES Module，无需 WebAssembly 或 Node.js 依赖，可直接运行在一集的 moejs 插件沙箱中。

## 功能

- **发现频道**：推荐、真人剧、漫剧
- **排行榜**：按类别与榜单筛选，支持短剧榜与演员榜
- **分类筛选**：按体裁联动更新题材、时间、排序等筛选项
- **搜索**：关键词搜索、搜索联想词、搜索首页热搜榜
- **详情与多季**：剧集列表、简介、多季切换与上新日历上线预告、相关推荐
- **演员主页**：个人简介、粉丝与获赞数据、参演作品列表
- **弹幕**：分页读取弹幕并将平台表情代码转为 emoji
- **播放**：匿名设备自动注册与失效换设备重试、返回多清晰度流与 CENC 内容密钥（由宿主选流和解密）

## 在一集中安装

1. 打开一集，点击侧栏顶部的片源切换按钮，进入 **管理片源…**。
2. 在 **发现** 中找到「红果短剧」安装，或在 **从仓库安装** 中输入：
   ```text
   giuem/ichiwa-hongguo
   ```
3. 确认插件权限后即可启用。

开发调试时，也可以在插件设置中开启 **开发者模式**，直接选择本仓库目录加载。

## 开发与测试

需要 Node.js 20+：

```bash
# 运行单元测试与逐字节算法对比测试
node --test

# 运行联网冒烟测试（遍历导航、榜单、筛选、搜索、详情、播放并 CENC 解密验证 MP4）
HONGGUO_LIVE=1 node --test test/live.test.js
```

如需重新生成 Go 参考测试向量（需要 Go 1.22+）：

```bash
go -C tools/vectors run . > test/vectors/vectors.json
```
